## 🔨 Сборка

> 💡 Нужен [**Rust**](https://www.rust-lang.org/tools/install) и Cargo

```bash
# 1️⃣ Клонируем репозиторий
git clone https://github.com/silcaelis/orbis.git
cd orbis

# 2️⃣ Собираем релиз
cargo build --release

# 3️⃣ Готово — бинарник в target/release/orbis
